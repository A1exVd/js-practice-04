### Вопросы к заданию

**В чём разница между mар() и forEach()? Когда использовать каждый?**
Метод map создает новый массив, состоящий из результатов вызова колбэка для каждого элемента исходного массива. Используется, когда необходимо получить новый массив на основе данных исходного. Метод forEach проходится по элемента исходного массива, выполняет колбэк, но не создает новый массив. 
ForEach используется, когда необходимо выполнить действие для каждого элемента.(вывод в консоль, обновить DOM)

**Что возвращает filter()? Изменяет ли он исходный массив?**
Возвращает новый массив содержащий элементы исходного массива, отобранные по заданному критерию. Немутирующий.

**Что такое JSON? Чем JSON-строка отличается от JavaScript-объекта?**
JSON (JavaScript object notation) - формат данных, который используется для передачи данных между фронтендом и бэкендом, при сохранении настроек в localstorage, при работе с API. Способ записи объектов или массивов в виде текстовой строки. Независимый формат, который понимают все языки.
Основные отличия от объекта:  
* Ключи обязательно в двойных кавычках  
* Строки только в двойных кавычках   
* Нет trailing comma(запятая после последнего элемента)   
* Не поддерживаются: функции, undefined, date, регулярные выражения  

**Что произойдёт, если передать в JSON.parse () невалидную строку?**
Ошибка синтаксиса «[object Object]” is not valid JSON. 

**Что такое деструктуризация объекта? Приведите пример из своего кода.**
Синтаксис позволяющий распаковывать свойства объекта, используя фигурные скобки. Например, 
const { name, price } =  {  
    id : 1, name: "Ноутбук ASUS", category: "Электроника", price: 2500, inStock: true  
    };

**Что делает оператор spread (...) при копировании объекта?**
При копировании объекта, spread оператор распаковывает в новый объект свойства исходного объекта. При таком копировании создается поверхностная копия.

**Почему нельзя сравнивать объекты через ===? Что выведет: () === ()?**
Потому что объект является ссылочным типом, то есть хранит не само значение, а адрес на область памяти, где данные реально расположены.
При сравнении двух объектов идёт сравнение ссылок, а не значений 
Если две переменные ссылаются на один и тот же объект, то true.

**Что такое метод reduce()? Как вы использовали его для подсчёта суммы?**
Метод reduce() применяет функцию reducer к каждому элементу массива, возвращая одно результирующее значение 
array.reduce(callback(accumulator, current value, index,array),initialvalue)
Аккумулятором была сумма, исходное значение 0, при каждой итерации добавляли текущее значение к сумме.
